# UI Improvement Prompt

Before we start integrating live data, we need to **fully redesign and polish the UI**. The focus of this phase is creating a modern, clean, and premium user experience.

### 1. Overall UI Design

* Use the **first reference** as the primary inspiration.
* The UI should be **minimal, elegant, and visually balanced**.
* Prioritize spacing, typography, alignment, and hierarchy to create a premium feel.
* The interface should feel modern and effortless, not cluttered.

### 2. Calculator UI

* Redesign the calculation screens to match the style and quality of the first reference.
* Keep the layout simple while making it visually appealing.
* Improve cards, input fields, buttons, and result sections with consistent spacing, subtle shadows, and smooth corners.

### 3. Icons

* **Do not use emojis anywhere in the application.**
* Replace every emoji with high-quality **illustration-style or professionally designed icons**.
* This applies to:

  * Sidebar
  * Bottom navigation
  * Cards
  * Empty states
  * Any other UI element
* Icons should have a consistent design language and feel modern and polished.

### 4. Gold Price Screen

* Use the **gold price references** as inspiration.
* The layout should be clean, organized, and premium.
* Include well-designed cards, charts, statistics, and pricing sections with proper visual hierarchy.
* Aim for a UI that is very close in quality and organization to the provided references.

### 5. Bottom Navigation

* Redesign the bottom navigation completely.
* Current icons feel outdated and inconsistent.
* Use clean, modern icons with a premium appearance.
* The navigation should feel lightweight and visually balanced.

### 6. Animations & Interactions

* Every interaction should feel smooth and polished.
* Add subtle animations for:

  * Switching between navigation tabs
  * Opening pages
  * Button presses
  * Cards
  * Loading states
  * Screen transitions
* Use smooth easing and modern motion—not flashy or distracting.
* The app should feel fluid and responsive.

### 7. Design Consistency

* Maintain a single design language throughout the application.
* Use consistent:

  * Colors
  * Typography
  * Border radius
  * Shadows
  * Spacing
  * Icon style
  * Components
* Every screen should look like part of the same premium product.

### Priority

**Do not start implementing live data yet.** The priority is to perfect the UI first. Once the entire interface reaches a polished, production-quality standard, we will move on to integrating live data.
